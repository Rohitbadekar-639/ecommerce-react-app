# E-commerce React Application

A modern, production-grade frontend-only React e-commerce application built with React 19, Vite, Tailwind CSS, and Zustand. This application is designed as a standout portfolio piece showcasing modern React development practices.

## 🚀 Features

### Core Functionality
- **Product Catalog**: Browse products with filtering (by category, price) and sorting options
- **Shopping Cart**: Full cart functionality with localStorage persistence
- **Payment Integration**: Razorpay test mode integration for checkout
- **Responsive Design**: Mobile-first responsive design that works on all devices
- **Modern UI/UX**: Clean, high-converting design with loading skeletons and toast notifications

### Technical Features
- **React 19**: Latest React version with modern hooks and patterns
- **TypeScript**: Full type safety throughout the application
- **State Management**: Zustand for lightweight, performant state management
- **Routing**: React Router for client-side navigation
- **Styling**: Tailwind CSS for utility-first styling
- **Component Architecture**: Modular, reusable components with clean separation of concerns
- **Custom Hooks**: Business logic encapsulated in custom hooks
- **Mock API**: Simulated API calls with realistic loading states

## 🛠️ Tech Stack

- **Frontend**: React 19, TypeScript
- **Build Tool**: Vite
- **Styling**: Tailwind CSS
- **State Management**: Zustand
- **Routing**: React Router
- **Payment**: Razorpay (test mode)
- **Icons**: Lucide React
- **Utilities**: clsx for conditional classes

## 🚀 Getting Started

### Prerequisites
- Node.js 18+ 
- npm or yarn

### Installation

1. Install dependencies:
```bash
npm install
```

2. Start the development server:
```bash
npm run dev
```

3. Open your browser and navigate to `http://localhost:5173`

### Build for Production

```bash
npm run build
```
